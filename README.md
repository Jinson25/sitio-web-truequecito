# 🌟 **Sitio Web Truequecito** 🌟

¡Bienvenido a **Truequecito**! Una plataforma de **intercambios y trueques** desarrollada con Angular, diseñada para facilitar la conexión entre usuarios que desean intercambiar productos de manera eficiente y segura. 🤝

---

## 📝 **Características Principales**

### 🔄 **Intercambios**
- 🚀 Propuesta de intercambios entre productos.
- 💳 Sistema de pago integrado con generación de comprobantes únicos.
- 📜 Gestión de estados de intercambio:  
  - ⏳ **Pendiente**  
  - ✅ **Aceptado**  
  - ❌ **Rechazado**  
  - 🎉 **Completado**  
- 🆔 Código único asignado a cada transacción.
- 🔍 Verificación de comprobantes realizada por administradores.

### 📦 **Productos**
- 📃 Listado completo de productos disponibles para intercambio.
- 🔍 Sistema avanzado de búsqueda y filtrado.
- 🖼️ Detalles individuales, como:
  - Estado.
  - Preferencias.
  - Imágenes.
- 🔧 Gestión personalizada de productos por cada usuario.

### 👤 **Usuarios**
- 🔐 Registro y autenticación mediante:
  - 🌐 Método local.
  - 🔵 Inicio de sesión con Google.
  - 🎮 Inicio de sesión con Discord.
- 👥 Perfiles públicos que muestran información y actividad.
- ➕ Sistema de seguimiento entre usuarios.
- 🏷️ Roles diferenciados:
  - **Usuario normal**.
  - **Administrador**.

### 🛠️ **Panel Administrativo**
- 🗂️ Gestión de intercambios completados.
- ✅ Verificación de comprobantes.
- 👥 Administración de usuarios y asignación de roles.
- 📊 Visualización de estadísticas generales.

---

## 🛠️ **Tecnologías**

El proyecto utiliza las siguientes tecnologías modernas:

- 🅰️ **Angular 17**: Framework para crear una interfaz de usuario moderna y dinámica.
- 💻 **TypeScript**: Lenguaje tipado que mejora la calidad del código.
- 🎨 **Tailwind CSS**: Framework para estilos rápidos y responsivos.
- 🎢 **SwiperJS**: Biblioteca para carruseles y deslizadores.
- 🔔 **SweetAlert2**: Alertas personalizadas y atractivas.

## 🚀 **Instalación**

1. **Clona este repositorio**:
   ```bash
   git clone https://github.com/tu-usuario/truequecito.git
    Accede al directorio del proyecto:
    Copiar código
    cd truequecito
   
    Instala las dependencias:
    npm install
   
    Inicia el servidor de desarrollo:
    ng serve
   
    Abre tu navegador y accede a:
    http://localhost:4200
